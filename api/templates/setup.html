Copy .env.example to .env and fill in:

  1. League id — from your league URL: fantasy.espn.com/football/league?leagueId=123456. Set BENCHCOACH_LEAGUE_ID.
  2. Is your league private? If yes you also need two session cookies. Log in to ESPN, open DevTools → Application → Cookies → espn.com, and copy espn_s2 and SWID into BENCHCOACH_ESPN_S2 and BENCHCOACH_SWID.
    These are full account access, not API keys. They stay in .env, which is gitignored — don't paste them anywhere else.
  3. Your team id — run python -m cli teams to list them, then set BENCHCOACH_TEAM_ID.
